# 第 2 周 · 会动的数字海报《山水的回响》

> Echoes of Landscape ／ p5.js 生成艺术 ／ 施俊妍 2026
> v2「暗夜星尘」· 1920×1080 成图见 `poster-*.png`

---

## 一、一句话

**手是风，山是介质，墨是留下来的痕迹。**
鼠标划过，雾海被吹开又自己合拢；点一下，荡开一圈回声。

---

## 二、画面上有什么（以及为什么这么减）

| 元素 | 作用 | 为什么留 |
|---|---|---|
| 夜空 + 星尘 | 呼吸感 | "回响"需要安静，星星是唯一会闪的东西 |
| 雾海（三层山脊） | 体量 | 大标题需要一个"沉"的底 |
| 大标题居中 | 气势 | 1920 宽下字号 ≈ 200px，占画面 1/2 |
| 左上/右侧/左下小字 | 制式感 | 参数、周次、题注，像一张正式印品 |
| 印章「回」 | 落款 | 朱红是唯一暖色，压住冷调 |

**删掉的东西**：月亮（和参考撞形）、指针墨点（会糊成一团）、细框内的装饰线。

---

## 三、技术

| 项 | 说明 |
|---|---|
| 框架 | p5.js 1.9.4（本地文件，无 CDN） |
| 粒子 | 1300 个，沿 Perlin 风场漂移，留 4 倍长度的短笔触 |
| 墨层 | 独立 `p5.Graphics`，`destination-out` 每帧褪色 0.28%，累积成雾 |
| 星尘 | 约 170 颗，`blendMode(ADD)` 双圆（核心 + 弱光晕），正弦相位错开闪烁 |
| 纸/雾 | 全部一次性烘焙到底图，不占运行时 |
| 导出 | `saveCanvas()`，导出时自动隐藏提示；按钮栏在 HTML 层，不会进图 |

---

## 四、交互映射（要求 ≥2 个，实际 4 组）

| 输入 | 映射 | 效果 |
|---|---|---|
| 鼠标位置 | 300px 半径径向风场 | 雾被推开，粒子改向 |
| 鼠标轨迹 | 延迟 16 / 34 / 56 帧回放 | 三个"幽灵风源"，强度 0.55 → 0.28 → 0.12，**这就是回声** |
| 点击 | 墨环扩张 + 粒子外推 | 一圈涟漪，α×0.968 衰减 |
| 按钮 / 1 2 3 | 换墨色 | 夜山 / 宣纸 / 赭石 |
| S | 导出 PNG | 当前帧成图 |
| 触屏拖动 | 同鼠标 | 手机上也能玩 |
